# Deliberately short. Every package here is one more thing that can fail to
# install on a reviewer's machine before they ever see the product, so each
# entry has to earn its place (ADR-007).
#
# Pinned to minor versions: a submission that worked yesterday and breaks today
# because a transitive dependency moved is indistinguishable, to a reviewer,
# from a submission that never worked.

# credentials at all.

#   - no vector database: passage retrieval is lexical first (ADR-008), and
#     SQLite's FTS5 ships with Python. A vector store would add a service to
#     the reviewer's critical path for a corpus of this size.
#   - no ORM migrations tool: the schema is created from the models at startup.
#     A 48-hour prototype with one schema version does not need Alembic, and
#     saying so is more honest than adding it for appearances.
#   - no frontend toolchain: server-rendered Jinja templates, so there is no
