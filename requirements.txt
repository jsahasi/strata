# Strata dependencies.

# Deliberately short. Every package here is one more thing that can fail to
# install on a reviewer's machine before they ever see the product, so each
# entry has to earn its place (ADR-007).
#
# Pinned to minor versions: a submission that worked yesterday and breaks today
# because a transitive dependency moved is indistinguishable, to a reviewer,
# from a submission that never worked.

# Model provider. app/interpretation/propose.py is the only place that imports
# it, and it imports it inside a function so that nothing pays for the SDK at
# import time. Everything else stays deterministic and testable without a key,
# which is what lets `make test` pass on a machine with no credentials at all.
#
# THE PIN MOVED, AND WHY. This read 0.39.* while nothing in app/ imported the
# package at all -- a declared dependency no code exercised, which is a claim
# the repo could not back. Now that a caller exists the pin has to match what it
# sends: 0.39 predates adaptive thinking and structured outputs, so
# `thinking={"type": "adaptive"}` and `output_config=` would both be rejected as
# unknown arguments before a request was ever built. A pin that cannot run the
# code beside it is worse than no pin, because it reads as tested.
anthropic==0.120.*

pytest==8.3.*
pytest-asyncio==0.24.*

#   - no ORM migrations tool: the schema is created from the models at startup.
#     A 48-hour prototype with one schema version does not need Alembic, and
#     saying so is more honest than adding it for appearances.
