Remaining gaps, prioritised

Recompiled 2026-08-07. Every row below was re-checked against the code on that date, not carried forward from the previous version of this page. The first version was compiled 2026-08-04; 64 commits have landed since, and most of what it listed is closed.

How to read the ordering. Priority here is not size of effort. It is what a reviewer hits first. A submission is read in a fixed order — the repository link, then the run command, then the screens, then the documents — and a defect early in that order hides everything good behind it. P0 items stop a reviewer at the front door. P1 items are false statements a reader could act on. P2 items are real code gaps that a panel question would expose. P3 items are things only we would notice.
What changed since 2026-08-04. All six P0 items and all four P1 items from that version are closed. Of twelve P2 items, nine are closed and two were narrowed to something smaller than they were. Of six P3 items, three are closed. The closed rows are listed at the foot of this page with what closed them, because a gaps list read alone tells a reader the wrong story about the state of the work.
One item is new, and it was found by recompiling this page. The suite was re-run rather than remembered, as this project's own rule requires, and it printed a different number from the one four documents carry. That is P1-5 below. It is the only row here that did not exist on 2026-08-04, and it is a small instance of the failure this page exists to catch.
