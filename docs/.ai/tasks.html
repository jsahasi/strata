Where the hours went, against the plan

Worth reading before planning the remaining hours, because the shape of the overrun is consistent. Phases 0 and 1 — the corpus and the deterministic engine — came in close to plan and are done. Phase 2 split: the state and audit machinery landed, the model-dependent half (T9, T10, T11's routing) did not, because the deterministic gate was built first on purpose and the model layer was always second. Phase 3 was rebuilt wider than planned after docs/.ai/demo-notes.html landed: projects, threads, work plans, scheduled runs, knowledge and a full review centre, which is where the extra 166 tests went. Phase 4 was skipped almost entirely. Phase 5 is where the debt sits.

The cheapest remaining work, in order: the README (T22, minutes, and it is the first thing read); make status to regenerate state.json (one command); committing the router mount and running fresh-check (T2); confirming repository visibility (T24). None of these is engineering. All four change what a reviewer sees first.

Cut list — if time runs short

Sacrifice in this order, and say so in the submission rather than hiding it: multi-jurisdiction taxonomy, rollback (keep audit history, drop the restore), the reviewer role model (one reviewer role instead of several), UI polish. Never cut: citation verification, the deterministic diff, draft-versus-final, or the user interviews. Those four are the submission's argument.

Cuts actually taken, so the list is a record and not just an intention: rollback is cut (T13). Amend in the review queue is cut (T16), which ADR-013 permitted in advance. The evals are cut (T17, T18's pass rate). Multi-jurisdiction taxonomy was never started. The user interviews are on the never-cut list and have not happened. That is the one cut nobody decided to take, which is the worst way to take one.
