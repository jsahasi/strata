Architecture

This material now lives in Part A of the Technical Design Document.

Moved 2026-08-04. This page is kept because 28 files in this repository link to it, and a dead link is a worse reader experience than a signpost.

Why it moved. Two descriptions of one system drift, and this pair had already drifted. The two documents disagreed about where normalization runs, about how segmentation splits a document, and about the similarity score of the restructure in the corpus — and an earlier revision of the data-flow drawing here put the citation gate on the wrong side of the write, as a write gate storing a verified flag, which is neither what the code does nor the better design. A reader holding two descriptions has no way to tell which one is wrong. So there is one now.

Nothing was dropped in the move. The structural material — the shape in one sentence, the data flow, the module tree, the dependency direction, the database ceiling, the deploy topology, the two corpora and the application surface — became Part A of the TDD, lettered A1 to A9 so it can never be mistaken for one of the eleven areas the brief names. The tenant chokepoint drawing moved to the section a reviewer ticks it under. Every figure came across as inline SVG.

Three things this page said that the code disagreed with, corrected in the move rather than carried over. That ingestion normalizes text — it does not, and normalization runs at verification time on both sides of every comparison, because normalizing before offsets exist would rewrite the text the offsets index. That segmentation follows paragraph, then section, with a fixed-size fallback — it splits on blank lines and nothing else, and section numbers only label a passage rather than end one. And that the restructure scores 0.944 — it does not, on the corpus as it stands; the run reports 19 changes, 8 capped, and 0.9904 on the pair the figure draws. The command that re-derives that is in A6.
