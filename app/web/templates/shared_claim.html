{# shared_claim.html — the page somebody with no account sees. IT DOES NOT EXTEND base.html, AND THAT IS THE POINT. base.html renders a masthead, a company name and six screens' worth of links. A share is one artifact, and a reader must not be able to walk from it into a proceeding, a project or a sibling claim. Inheriting the shell would put every one of those links on the one page nobody had to sign in to reach, and the failure would look like a styling decision rather than an access-control one. Two states, one file: available = true the artifact, re-verified a moment ago available = false expired, revoked or unknown -- one answer for all three The refusal state renders NOTHING derived from the request. No token, no id, no timestamp, no count. Three responses that differ by a byte would let a caller tell a withdrawn link from one that never existed, which is a probe for which tokens are real. Context, available = true: watermark, watermark_note str what this page is heading str the artifact, e.g. "Section 2.1" source_label str the document the quote came from shared_by str who sent it shared_at, expires_at datetime when, and until when opened_at datetime when the check below ran verified ClaimPanel[] claims that may be asserted withheld RefusalPanel[] claims the product refuses to make nothing_to_show str shown when both lists are empty call_to_action(_note) str the one way in Context, available = false: unavailable_heading, unavailable_text, call_to_action The two lists are iterated separately and there is no flag to branch on. WithheldClaim has no statement field and cannot be given one, so a mistake in this file cannot leak an assertion -- it can only fail to render. #} {% if page_title %}{{ page_title }} · Strata{% else %}Strata{% endif %}
