What each row shows instead is a preflight: this product reads the address you typed and says whether a fetcher would be permitted to reach it. Would be allowed means nothing here refuses that address in advance. It does not mean the address answered, or exists, or holds a filing. No socket was opened and no name was resolved, and a name that passes can still resolve to an address inside this network -- which is why there is no fetch button behind it.

A source whose address would be refused can still be registered, and some legitimate ones are: an internal document store is inside this network by definition. The verdict is recorded beside the row rather than used to block it, so whoever builds the first fetcher inherits the warning instead of the assumption.
